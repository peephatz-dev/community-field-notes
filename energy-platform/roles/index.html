นาย

สถาปัตยกรรมและภาพรวมระบบ

เชื่อมพื้นที่ท่าเรือลุงทอง แนวบ้าน และกลุ่มกระชังเข้ากับ P0–P3 กำหนดว่าข้อมูลเดินอย่างไร ไฟสำรองรักษาโหลดใด และขอบเขตไหนยังเป็นข้อเสนอ

สิ่งที่ต้องส่ง

ผัง architecture + power/data flow + เหตุผลลำดับ P0 > P1 > P2 > P3 + ขอบเขตทดลองแรงดันต่ำ

ช่วยกันทำ / ส่งต่อ

ส่งขอบเขตและ interface ให้โฟล์ค/บอส แล้วตรวจความสอดคล้องของ dashboard กับพี

โฟล์ค

เซนเซอร์ วงจร และความปลอดภัยไฟฟ้า

เลือกแนวทางวัดแรงดัน กระแส ความเค็ม และอุณหภูมิ ตรวจ interface โพรบ แหล่งจ่าย การซีล และการป้องกันให้เหมาะกับการทำงานริมน้ำ

สิ่งที่ต้องส่ง

วงจรอ้างอิงแรงดันต่ำ + BOM/พิกัดที่ต้องยืนยัน + ขั้นตอนสอบเทียบ + แผนตรวจโหลดและ startup current

ช่วยกันทำ / ส่งต่อ

ส่งหน่วย/ช่วงวัด/quality flag ให้พี และ pin/interface ให้บอส; ให้ผู้มีความรู้ตรวจวงจรก่อนต่อจริง

พี

ข้อมูล Dashboard กราฟ และการแจ้งเตือน

แสดงไฟหลัก บัสสำรอง โหลด และค่าน้ำให้แยกความหมายกัน ทำกราฟที่ไม่เติมค่าศูนย์แทนเซนเซอร์เสีย และทำ alert ที่บอกจุด เวลา ผลกระทบ และ action

สิ่งที่ต้องส่ง

dashboard + นิยามข้อมูล/หน่วย + event/alert view + JSON/CSV + ตัวอย่างกรณีข้อมูลขาดหรือผิดปกติ

ช่วยกันทำ / ส่งต่อ

รับ schema จากบอสและช่วงวัดจากโฟล์ค; ส่งภาพและหลักฐานเดโมให้ข้าวฟ่างตรวจคำกล่าว

บอส

การสื่อสาร ข้อความโหนด และ State

กำหนดข้อความ P1–P3 ไป P0 ลำดับ seq เวลารับล่าสุด การตรวจ stale/offline และการฟื้นระบบ โดยแยกการขาดการสื่อสารออกจากไฟดับ

สิ่งที่ต้องส่ง

message schema + state transitions + timeout/recovery rules + แผนทดสอบเครือข่ายในแนวบ้านและกลุ่มกระชัง

ช่วยกันทำ / ส่งต่อ

ส่ง schema ให้พี และข้อกำหนด interface ให้โฟล์ค; ตรวจ event history และ restoration flow ร่วมกับนาย

ข้าวฟ่าง

เอกสาร การยืนยัน และการอธิบาย

ผูกคำกล่าวกับ Data Pack และภาพอ้างอิง ระบุสิ่งที่เห็น ข้อเสนอ ค่าจำลอง และส่วนที่ยังต้องลงพื้นที่ ทำสไลด์/เรื่องเล่าให้คนทุกสายเข้าใจตรงกัน

สิ่งที่ต้องส่ง

evidence/validation checklist + เอกสารขอบเขตและข้อจำกัด + Presentation + แผนถ่าย Video Walkthrough จากงานจริง

ช่วยกันทำ / ส่งต่อ

ตรวจข้อมูลกับทุกคนก่อนส่ง; นัดผู้เลี้ยง/ผู้ดูแลเพื่อยืนยันโจทย์ โหลด จุดวัด และผู้รับเหตุ

ทั้งทีมช่วยกันยืนยัน ปัญหาจริงและ workflow เดิม · ลำดับโหลด · จุดติดตั้งที่เข้าถึงได้ · ผู้รับเหตุ · วิธีวัดผล ก่อนกำหนดคำกล่าวว่าจะใช้งานจริงได้
