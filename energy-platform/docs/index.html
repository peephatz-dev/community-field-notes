ENGINEERING NOTES

เอกสารวิศวกรรมและแหล่งข้อมูล

แยกข้อมูลจาก Data Pack ข้อกำหนดในเอกสารทีม แบบเสนอทางวิศวกรรม และช่องว่างภาคสนาม

Source of truth

ระดับที่มาของข้อมูลและสถานะการยืนยัน

เอกสารพื้นที่ระบุ

Data Package ระบุไฟตกบ่อยทั้งชุมชน บางบ้านใช้โซลาร์แต่ยังไม่พอ และมีหน่วยงานตรวจค่าน้ำ/DO/ตะกอนอยู่แล้ว (หน้า 6 จากไฟล์ที่อ่านได้)

เอกสารทีมกำหนด

P0–P3; P0 เป็น node หลัก; P1 เชื่อมไฟกับน้ำ; แรงดันต่ำและไม่ควบคุมไฟบ้าน; P3 ตัดก่อน P2; โซลาร์/แบตจริงเป็นส่วนต่อยอด

แบบเสนอทางวิศวกรรม

12V DC demonstration bus, fuse, battery/BMS, DC-DC, sensing, driver และแนวทาง telemetry ที่แสดงในแอป — เป็นโครงอธิบายเพื่อการพัฒนา ยังไม่ใช่ schematic ผ่าน review

ค่าจำลอง

โหลด (30/120/80/260 W), battery 1.2 kWh, threshold SoC 28%, voltage sag 9.7 V, อุณหภูมิ/ความเค็ม และเวลาเร่ง 1 นาทีต่อวินาที

ยังไม่ทราบ

ระดับและความถี่ไฟตกจาก log, โหลด/กระแสจริง, อุปกรณ์และพิกัดวงจร, ความจุแบตเตอรี่, จุดติดตั้ง, ตัวรับแจ้ง, การทำงานของระบบเดิม, ค่า DO real-time และความเต็มใจ/การยินยอมของผู้ใช้

ข้อจำกัดและเงื่อนไขใช้จริง

สิ่งที่ต้องเพิ่มก่อนนำไปติดตั้ง

ไฟฟ้าและความปลอดภัย

ยังไม่มี rating ของสาย ฟิวส์ BMS charger DC/DC หรือ switching module; วงจรในหน้านี้ห้ามใช้ต่อไฟบ้าน/กระชังจริง

น้ำเค็ม ความชื้น และไอเกลือ

ต้องระบุ enclosure, connector, corrosion test, leakage protection และการติดตั้งให้ห่างจากน้ำ/คน

ข้อมูลน้ำและการเพาะเลี้ยง

มีหน่วยงานและระบบติดตามในพื้นที่อยู่แล้ว; ตรวจการซ้ำซ้อน/owner ของข้อมูลก่อนพัฒนา sensor ใหม่; DO ต้องมีหัววัดและสอบเทียบแยก

การตอบสนอง alert

ต้องมีผู้รับและ action ที่ยอมรับร่วมกัน พร้อมทดสอบ stale / false alarm / ไฟมาแล้วแบตต่ำ

ความเป็นส่วนตัวและความยินยอม

ก่อนสัมภาษณ์หรือเก็บข้อมูลที่ระบุตัวบุคคล ให้ระบุวัตถุประสงค์และขอความยินยอม; demo นี้ไม่มีข้อมูลส่วนบุคคลจริง

รายการการยืนยันภาคสนาม

เก็บหลักฐานก่อนยกระดับจาก demonstrator ไปสู่การติดตั้ง

ประเด็นผู้ให้ข้อมูล/เครื่องมือสิ่งที่ต้องได้สถานะ
เหตุไฟตก/ดับครัวเรือน/ผู้ดูแลไฟ + meter loggerวันเวลา ระยะเวลา แรงดันต่ำสุด และโหลดที่ได้รับผลยังไม่มี log ในข้อมูลที่แนบ
โหลดสำคัญผู้เลี้ยงปลา / ผู้ดูแลอุปกรณ์W, startup current, runtime และลำดับที่ต้องคงไว้รอตรวจหน้างาน
วงจร/แบตเตอรี่ช่างไฟ/วิศวกรBOM, ratings, protection, battery chemistry, wiring reviewยังไม่มี design sign-off
การแจ้งเตือนผู้ใช้และผู้ดูแลผู้รับ วิธีตอบสนอง ช่องทาง และความเสี่ยง false alarmรอ co-design
น้ำศูนย์วิจัยประมง / NECTEC / ผู้เลี้ยงระบบที่มี จุดวัด calibration ความถี่ และสิทธิ์ใช้ข้อมูลต้องประสานก่อนซ้ำซ้อน
