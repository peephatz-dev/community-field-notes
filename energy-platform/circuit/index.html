Smart Sala-Hum Prototype

ผัง Mermaid ที่ผู้ใช้ส่ง 16 ตุลาคม 2569 (ฉบับเต็ม) · ผังที่ทีมเสนอครบทั้ง P0–P3 · ยังไม่ใช่ผลทดสอบฮาร์ดแวร์

P0 · Master Power Node

กล่องกันน้ำแยกโหนด · ระดับ IP ยังไม่ระบุ

  • Mini Solar Cellตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • Multi-Source DC Input Managerตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • 18650 #1ตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • 18650 #2ตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • Dual-Rail UPS Battery Systemตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • 2-Way Power Managerตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • ESP32-S3ตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • Voltage / Current / Stability Monitorตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • Relay Power Distributionตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน

P1 · Water Quality Node

กล่องกันน้ำแยกโหนด · ระดับ IP ยังไม่ระบุ

  • 18650 Batteryตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • Single-Rail UPSตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • ESP32ตามผังผู้ใช้; รุ่น/พิกัด/จุดต่อจริงยังต้องยืนยัน
  • EC Sensorหัววัด EC ตามผัง; รุ่น ช่วงวัด หน่วย และการสอบเทียบยังต้องยืนยัน
  • Temperature Sensorหัววัดอุณหภูมิตามผัง; รุ่น/ช่วงวัดยังต้องยืนยัน
  • Voltage / Current / Stability Monitorมอนิเตอร์ไฟ P1 ตามผัง; รุ่น/พิกัดยังต้องยืนยัน

P2 · Essential Monitoring Node

กล่องกันน้ำแยกโหนด · ระดับ IP ยังไม่ระบุ

  • 18650 Batteryแบตเตอรี่ P2 ตามผัง; พิกัด/การต่อยังต้องยืนยัน
  • Single-Rail UPSUPS แยกของ P2 ตามผัง; รุ่น/พิกัดยังต้องยืนยัน
  • ESP32ตัวควบคุม P2 ตามผัง; pin/firmware ยังไม่ระบุ
  • Voltage / Current / Stability Monitorมอนิเตอร์ไฟ P2 ตามผัง; รุ่น/พิกัดยังต้องยืนยัน

P3 · General Monitoring Node

กล่องกันน้ำแยกโหนด · ระดับ IP ยังไม่ระบุ

  • 18650 Batteryแบตเตอรี่ P3 ตามผัง; พิกัด/การต่อยังต้องยืนยัน
  • Single-Rail UPSUPS แยกของ P3 ตามผัง; รุ่น/พิกัดยังต้องยืนยัน
  • ESP32ตัวควบคุม P3 ตามผัง; pin/firmware ยังไม่ระบุ
  • Voltage / Current / Stability Monitorมอนิเตอร์ไฟ P3 ตามผัง; รุ่น/พิกัดยังต้องยืนยัน
ผังระบุการเชื่อมต่อ: P0–P3 มี 26 ลูกศรตามแบบ รวม RELAY จ่าย 5V ไป P1–P3 และ ESP1–ESP3 ส่ง Data เข้า ESP0 · รุ่นโมดูล พิกัด และผลทดสอบจริงยังต้องยืนยัน
รายการที่ต้องยืนยันก่อนประกอบและติดตั้ง
  • รุ่นและพิกัด Mini Solar, DC Input Manager, Power Manager และ UPS ทุกโหนด
  • ความจุเซลล์ การต่อแบตเตอรี่ วงจรชาร์จ/ป้องกัน และเวลาสำรองจริงของแต่ละกล่อง
  • รุ่น/ช่วงวัด/การสอบเทียบของ EC, Temperature และ Voltage/Current/Stability Monitor
  • พิกัดโหลดที่รับจาก 5V ของ P1–P3, การป้องกันและการคุม Relay
  • transport/protocol, รูปแบบข้อความ, update rate, ความปลอดภัย และการจัดการ ESP1–ESP3 ถึง ESP0
  • ผลทดสอบ bench ของไฟฟ้าและสื่อสาร รวมถึงจุดติดตั้งและระดับ IP
