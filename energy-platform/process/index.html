11 ขั้นจากจุดวัด ถึงคนรับเหตุ

กดสถานการณ์แล้วดูป้ายสถานะในแต่ละขั้นเปลี่ยนตามตัวจำลองเดียวกับฉากและ Dashboard

  1. 01
    Sensing

    ตรวจไฟและค่าน้ำ ณ จุดที่เสนอ

    P1 ใกล้กลุ่มกระชังเป็นจุดหลัก เสนอ B สำหรับสังเกตแนวเปลี่ยนสีและ C สำหรับเปรียบเทียบ ต้องกำหนดเครื่องมือ เวลา ความลึก และการสอบเทียบก่อนติดตั้ง

    ค่าน้ำสังเคราะห์ · B/C ยังไม่มีเครื่องมือ
  2. 02
    Node processing

    ประมวลผลและติดป้ายคุณภาพ

    โหนดตรวจ range ความสมเหตุสมผล และข้อมูลขาด ก่อนส่งค่า หน่วย seq และ quality flag ไม่ตีความเซนเซอร์เสียเป็นน้ำวิกฤต

    ตัวอย่างอินพุตจำลองพร้อม quality label
  3. 03
    Communication

    ส่ง P1–P3 ไป P0

    ตรวจ seq และ last_seen เพื่อแยก online/stale/offline ระยะบ้านถึงกระชังและสิ่งกีดขวางต้องตรวจสัญญาณจริง

    ไม่มีเครือข่ายจริง · จำลองการรับข้อมูล
  4. 04
    P0 aggregation

    รวมข้อมูลที่ศูนย์ควบคุมริมฝั่ง

    P0 รวบรวมข้อมูลไฟ โหลด เซนเซอร์ และเวลา สงวนข้อมูลต้นทางและบันทึกเหตุ โดยตำแหน่งบนผังยังเป็น PROPOSED

    1 records · T+0
  5. 05
    Event evaluation

    จำแนกเหตุและผลกระทบ

    ประเมินไฟหลัก การสื่อสาร และคุณภาพเซนเซอร์แยกกัน น้ำเปลี่ยนจากอินพุตจำลองต้องเทียบเครื่องอ้างอิง ไม่ใช้สีผิวน้ำยืนยันความเค็มหรือ DO

    ไฟหลักปกติ
  6. 06
    Backup decision

    ประเมินพลังงานที่จะคงโหลด

    เมื่อไฟหลักดับ ประเมินแบตเตอรี่และบัสสำรองก่อนจ่ายโหลด ความจุและแรงดันที่เห็นเป็นค่าตัวอย่าง ต้องวัดโหลด/สูญเสีย/startup current จริง

    ไฟหลักจ่าย · ไม่จำลองการชาร์จ
  7. 07
    Load prioritization

    ตัด P3 ก่อน และคงโหลดสำคัญ

    P0 > P1 > P2 > P3 เป็นนโยบาย ไม่ใช่การต่ออนุกรม P2 หยุดเมื่อสำรองต่ำกว่า 28% และ P1 หยุดเมื่อไม่พอขอบเขต 8% ในเดโม

    P1 คง · P2 คง · P3 คง
  8. 08
    Dashboard update

    อัปเดตกราฟและสถานะร่วมกัน

    กราฟไฟหลัก บัสโหลด กระแส แบตเตอรี่ และค่าน้ำใช้ state กลางเดียวกับฉาก/วงจร หน่วยและสถานะจำลองต้องติดกับทุกค่า

    ไฟหลัก 12.1 V · บัส 12.1 V
  9. 09
    Alerting

    แจ้งว่าอะไรเกิด ที่ไหน และควรทำอะไร

    บอกโหนด เวลา ความรุนแรง ความหมาย และ recommended action การแจ้งเตือนในเว็บยังไม่ส่ง LINE/SMS หรือสั่งงานอุปกรณ์จริง

    SYSTEM · info
  10. 10
    Human response

    ให้ผู้รับเหตุยืนยันหน้างาน

    ผู้เลี้ยง/ผู้ดูแลตรวจอุปกรณ์ น้ำ และเครื่องอ้างอิงตามบทบาทที่ตกลง ผู้บำรุงรักษาตรวจวงจร/สื่อสาร และจด action เพื่อประเมิน false alarm

    รอยืนยันผู้รับเหตุและวิธีตอบสนองจริง
  11. 11
    Recovery

    คืนโหลดตามลำดับและเก็บประวัติ

    เมื่อไฟหลักกลับ เดโมคืน P0/P1 ก่อน แล้ว P2 และ P3 ตามการเดินเวลา เก็บ SoC ประวัติ และ fault เดิมเพื่อให้ตรวจสอบย้อนหลัง

    โหลดที่อนุญาตพร้อมทำงาน
