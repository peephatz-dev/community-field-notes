สถาปัตยกรรม P0–P3

แสดงทางเดินพลังงาน ทางเดินข้อมูล และกติกาลำดับโหลดจากเอกสารทีม

โครงสร้างพลังงาน · นโยบายลำดับโหลด

ลำดับความสำคัญไม่ใช่การต่อ load เป็นอนุกรม และ P0 ไม่ได้แบกกระแสโหลดทุกตัว

แหล่งจ่ายหลักutility / renewable (future scope)
↓ power input · reference
F1 · DC Bus · monitorโมเดลแรงดันต่ำเพื่อการสาธิต; พิกัดยังไม่กำหนด
↓ source + storage path
Battery + BMS / charger (เสนอ)ไม่ใช่อุปกรณ์ที่ยืนยันในต้นแบบตามเอกสารทีม
P0 · P0 priorityศูนย์ควบคุม30 W · load model only

รับข้อมูล ประเมินเหตุ จัดลำดับโหลด และบันทึกเหตุการณ์

P1 · P1 priorityประมงและโหลดวิกฤต120 W · load model only

ติดตามแรงดัน กระแส ความเค็ม และอุณหภูมิ พร้อมโหลดสาธิตสำคัญ

P2 · P2 priorityโหลดชุมชนจำเป็น80 W · load model only

ไฟส่องสว่างและอุปกรณ์จำเป็น ทำงานต่อเมื่อกำลังสำรองพอ

P3 · P3 priorityโหลดทั่วไป260 W · load model only

โหลดทั่วไปหรือโหลดสาธิตกำลังสูง ตัดก่อนเมื่อพลังงานจำกัด

Policy เมื่อพลังงานจำกัด P0P1P2P3ตัด P3 ก่อน แล้ว P2 เมื่อพลังงานต่ำ · P1/P0 เป็นแกนที่รักษาไว้จนเข้าเงื่อนไขป้องกันแบตเตอรี่
