# ผังอ้างอิงท่าเรือลุงทองและกระชังบ้านศาลาหุม

## แหล่งอ้างอิงหลัก

ผู้ใช้ระบุพื้นที่ว่า **ท่าเรือลุงทองและบริเวณกระชังเลี้ยงปลา บ้านศาลาหุม อำเภอสิงหนคร จังหวัดสงขลา** พร้อมภาพหน้าจอ Google Maps และ [ลิงก์ตำแหน่งที่ผู้ใช้ส่ง](https://maps.app.goo.gl/ijj24HM8Fcy4gBfQ7?g_st=ic)

ภาพหน้าจอเป็นแหล่งอ้างอิงหลักสำหรับ **ตำแหน่งสัมพัทธ์ สัดส่วน แนววาง และช่องว่างระหว่างองค์ประกอบ** ไม่ใช่แผนที่สำรวจ ภาพไม่มีมาตราส่วนและทิศเหนือที่ยืนยันได้ วันที่ของภาพดาวเทียมไม่ทราบ ชื่อท่าเรือมาจากข้อมูลที่ผู้ใช้ให้ ส่วนจุดเริ่มท่าที่เลือกในโมเดลเป็นแนวท่ายาวบริเวณช่วงล่างของภาพ ไม่ใช่พิกัดติดตั้งที่ตรวจภาคสนามแล้ว

ไม่จัดเก็บภาพ Google Maps ไว้ในโฟลเดอร์ที่เผยแพร่ ไม่ใช้ภาพเป็น texture หรือ map tiles เนื้อหาที่เผยแพร่เป็นรูปทรงและผังที่วาดใหม่ พร้อมลิงก์กลับไปดูตำแหน่งจากต้นทาง หากต้องการภาพอ้างอิงซ้อนในอนาคต ต้องใช้ภาพที่ทีมมีสิทธิ์เผยแพร่ก่อน

## ระบบพิกัดภาพและการแปลงเป็นฉาก

ข้อมูลกลางอยู่ที่ `src/lib/site-layout.ts` และเป็นต้นทางเดียวของผัง 2D ฉาก 3D และตำแหน่งเสนอ P0–P3

| เรื่อง | นิยาม |
| --- | --- |
| ภาพต้นฉบับ | 591 × 1,280 พิกเซล |
| ส่วนภาพที่ใช้เทียบผัง | x = 0–591, y = 220–1,142 พิกเซล |
| พิกัด u | 0 = ซ้าย, 1 = ขวา ของส่วนภาพ |
| พิกัด v | 0 = บน, 1 = ล่าง ของส่วนภาพ |
| มุมมองด้านบน | u ไปทาง world +x, v ไปทาง world +z; ด้านบนภาพไม่ติดป้ายว่าเป็นทิศเหนือ |
| ขนาดฉาก | กว้าง 46 composition units; ความลึกคงอัตราส่วน 922/591 ของภาพ |
| จุดกำเนิดฉาก | u = 0.42, v = 0.5 เพื่อจัดกล้องให้เห็นแนวฝั่งและกระชัง |
| หน่วย | หน่วยจัดองค์ประกอบ ไม่ใช่เมตร และไม่แสดงระยะจริงจากผัง |

ฟังก์ชัน `siteToWorld(u, v, height)` และ `worldToSite(x, z)` แปลงพิกัดกลับไปมาโดยไม่สร้างละติจูด/ลองจิจูด `footprintCorners()` หมุน footprint ในอัตราส่วนพิกเซลเดิม เพื่อไม่ให้แนวยาวของกระชังผิดมุมเมื่อเปลี่ยนจากภาพแนวตั้งเป็นฉาก

## สิ่งที่สังเกตได้และสิ่งที่ใช้สร้างใหม่

| องค์ประกอบ | สิ่งที่เห็นในภาพ | การใช้ในฉาก | ข้อจำกัด |
| --- | --- | --- | --- |
| แนวฝั่ง | แนวอาคารและพื้นที่ฝั่งอยู่ด้านซ้าย ขยายไปทางขวาช่วงล่าง ขอบริมน้ำไม่เป็นเส้นตรง | เส้นขอบฝั่งประมาณและ polygon ของพื้นที่ฝั่ง | ไม่ใช่แนวกรรมสิทธิ์/แนวระดับน้ำขึ้นลง และไม่ได้ยืนยันขอบฐานบ้านแต่ละหลัง |
| ถนน | แนวสีอ่อนด้านซ้ายตามแถวบ้าน โค้ง/เฉียงเข้าไปทางขวาช่วงล่าง | centerline ถนนตามแนวภาพ | ความกว้างเป็นสัดส่วนเพื่อเรนเดอร์ ไม่ใช่ผลวัดถนน |
| อาคารริมน้ำ | กลุ่มหลังคาหนาแน่น หลายสีและขนาด อยู่ระหว่างถนนกับน้ำ | footprint หลังคาตัวแทนที่วางเป็นรายจุด | จำนวน footprint ไม่เท่ากับจำนวนครัวเรือน; รูปทรงหน้าบ้าน/จำนวนชั้นไม่ทราบ |
| ท่าเรือ | แนวยาวเด่นช่วงล่าง ยื่นจากแนวฝั่งไปทางขวาบนของภาพ | เส้นหลายจุดจาก (.426,.715) ถึง (.65,.656) | เป็นจุดจับคู่ภาพโดยประมาณ ต้องให้คนพื้นที่ยืนยันชื่อและจุดเริ่มท่า |
| กระชัง | แนวกรอบสี่เหลี่ยมหลายกลุ่ม แกนยาวไปทางขวาบน มีแถวสั้นและกลุ่มแยกออกจากกัน | `CAGE_RUNS` กำหนดกลุ่มและทิศทาง; `CAGE_CELLS` แบ่งเป็นช่องตัวแทน | divisions/จำนวนช่องเป็นการสร้างใหม่ ไม่ใช่จำนวนกระชังจริง; ภาพอาจถ่ายคนละเวลากับปัจจุบัน |
| ช่องน้ำ | ช่องว่างระหว่างกลุ่มกระชัง และพื้นที่น้ำเปิดก่อนถึงแนวท่ายาว | คงพื้นที่ว่างและเว้นทางระหว่าง run | ไม่ใช่การยืนยันร่องน้ำเดินเรือ ความลึก หรือทิศกระแสน้ำ |
| เรือ | เรือเล็กอยู่ใกล้แนวบ้าน ปลายท่า และริมฝั่งช่วงล่าง | เรือขนาดเล็กวางตามตำแหน่งตัวแทน | จำนวน ประเภท เจ้าของ และขนาดจริงไม่ยืนยัน |
| พืชพรรณ | กลุ่มพืชเข้มตามแนวถนนช่วงล่างและข้างท่า | vegetation patches ตามตำแหน่งในภาพ | ชนิดและความสูงเป็นองค์ประกอบสร้างใหม่ ไม่ใช่ผลสำรวจพรรณไม้ |
| ถนน/โครงสร้างคล้ายสะพาน | แถบถนน/ขอบโครงสร้างที่มุมล่างซ้ายเห็นเพียงบางส่วน | เก็บแนวถนนที่มองเห็น | ไม่ยืนยันว่าเป็นสะพาน ไม่ต่อโครงสร้างนอกภาพด้วยรูปทรงที่อ้างว่าเป็นสถานที่จริง |
| พื้นที่ด้านบน | มีแถบค้นหา ปุ่มหมวด และ UI บังส่วนสำคัญ | จำกัดผังให้เริ่มใต้แถบ UI และทำเครื่องหมายพื้นที่ไม่ทราบ | กระชังที่เห็นบางส่วนเหนือ crop ไม่ใช้ขยายผังเป็นจำนวนแน่นอน |

สิ่งที่ดูคล้ายวัสดุ เช่น หลังคาโลหะ ไม้ ตาข่าย ทุ่น และเรือ ใช้สร้างลักษณะอุปกรณ์ที่สมเหตุสมผลร่วมกับภาพภาคสนามเดิมของโครงการ วัสดุ PBR รายละเอียดทางวิศวกรรม สายไฟ และตู้ P0–P3 เป็นการสร้างใหม่ ไม่ใช่การอ่านจากภาพดาวเทียม

## แนวสีของน้ำ: สังเกตได้ แต่ยังจัดประเภทความเค็มไม่ได้

ในภาพ น้ำช่วงกลุ่มกระชังด้านบนมีสีเขียวหม่น ส่วนใกล้แนวท่ายาวและด้านล่างมีสีฟ้า/น้ำเงินเข้มกว่า โมเดลเก็บ **แนวเปลี่ยนสีโดยประมาณ** ไว้ใน `WATER_TRANSITION` เพื่อให้เห็นบริบทที่ผู้ใช้สังเกต

สีที่ต่างกัน **ยังไม่ยืนยันว่าบริเวณหนึ่งเป็นน้ำจืด น้ำกร่อย หรือน้ำทะเล** และไม่ยืนยันขอบน้ำเบียด สาเหตุอาจเกี่ยวข้องกับคุณสมบัติของน้ำ ตะกอน ความลึก การสะท้อนแสง หรือสภาพการบันทึกภาพ แต่ภาพเดียวไม่แยกสาเหตุเหล่านี้ได้ จึงไม่ใส่ชื่อประเภทความเค็มลงบนพื้นที่น้ำจากสี ไม่สร้างค่าความเค็มหรือ dissolved oxygen ที่วัดจริงจากภาพ

การยืนยันภาคสนามควรเก็บ: เวลา/ระดับน้ำ จุดวัดความเค็มหรือ conductivity เครื่องอ้างอิงที่สอบเทียบแล้ว อุณหภูมิ จุดและความลึกของหัววัด และตัวอย่างหลายจุดสองฝั่งแนวสี หากต้องการศึกษาออกซิเจนละลายน้ำ ต้องมีเครื่องวัด DO โดยตรง ไม่อนุมาน DO จากสี อุณหภูมิ หรือความเค็มเพียงอย่างเดียว

## จุด P0–P3 ที่เสนอ

ทุกตำแหน่งมีสถานะ **PROPOSED · รอยืนยันจากการสำรวจพื้นที่** ค่าโหลดและวงจรยังใช้แบบจำลองเดิม การย้ายตำแหน่งในฉากไม่เปลี่ยนลำดับความสำคัญหรือสมการพลังงาน

| จุด | ตำแหน่งสัมพัทธ์ในภาพ | เหตุผลในการเสนอ | สิ่งที่ต้องยืนยัน |
| --- | --- | --- | --- |
| P0 | ใกล้แนวฝั่ง ณ จุดเริ่มท่ายาวโดยประมาณ | สาธิตจุดควบคุม เกตเวย์ และพลังงานสำรอง | ผู้ดูแล พื้นที่อนุญาต ระดับน้ำ/น้ำท่วม แหล่งไฟ และระยะสื่อสารจริง |
| P1 | ใกล้กลุ่มกระชังช่วงกลาง | สาธิตการติดตามน้ำและโหลดวิกฤตใกล้กิจกรรมเพาะเลี้ยง | กระชังเป้าหมาย การยินยอม จุดยึด ความลึกหัววัด การเข้าถึงเพื่อบำรุงรักษา |
| P2 | แนวอาคารริมน้ำ | สาธิตโหลดจำเป็นของชุมชน | โหลดที่มีอยู่จริง แรงดัน กำลังใช้งาน ความสำคัญ และเจ้าของโหลด |
| P3 | ใกล้ถนน/จุดเข้าถึงด้านฝั่ง | แสดงโหลดทั่วไปที่สามารถตัดก่อนเพื่อรักษาพลังงานสำรอง | ต้องเลือกโหลดสาธิตที่ยอมรับให้ตัดได้ ไม่อ้างว่าบ้านจริงเป็นโหลดไม่จำเป็น |

เส้นเชื่อมไฟฟ้าและ telemetry เป็น **topology ที่เสนอ** ไม่ใช่เส้นทางสายที่ติดตั้งจริง ไม่มีการสมมติว่าทุกบ้านเป็นสมาชิกของระบบ หรือว่าตู้ควบคุมมีอยู่แล้วในตำแหน่งที่วาง

## หลักการเปรียบเทียบในเว็บไซต์

- ผัง 2D คือภาพวาดใหม่ที่ตามตำแหน่งสัมพัทธ์ของภาพอ้างอิง และต้องระบุว่าเป็น reconstruction
- มุม top-down ใช้แกนภาพเดียวกับผัง มุม oblique แสดงความสัมพันธ์ของแนวบ้าน กระชัง และท่า
- reference overlay ซ้อน **เส้น trace ที่ทีมวาดใหม่** ไม่ซ้อนภาพ Google Maps ที่ไม่มีสิทธิ์เผยแพร่
- ปรับ opacity เปิด/ปิด landmarks และ reset camera ได้ โดยต้องไม่ทำให้ค่าทางไฟฟ้าหรือประวัติเหตุการณ์รีเซ็ต
- ป้าย PROPOSED ต้องอยู่ทั้งแผงรายละเอียดและตำแหน่งบนผัง/ฉาก
- ข้อเท็จจริงที่ยืนยันได้คือรูปแบบทั่วไปในภาพ; ความสูงอาคาร รูปทรงตู้/เรือ ความลึกน้ำ และตำแหน่งติดตั้งเป็นสิ่งสร้างใหม่หรือรอภาคสนาม

## รายการที่ควรเก็บเพิ่มก่อนใช้เป็นแผนติดตั้ง

1. ให้คนพื้นที่ตรวจความตรงของท่า ถนน กลุ่มกระชัง และจุด P0–P3 บนภาพวาดใหม่
2. ภาพภาคพื้นดินที่ทีมมีสิทธิ์เผยแพร่ พร้อมวันที่และมุมถ่าย; หากใช้โดรน ต้องมีสิทธิ์และเงื่อนไขที่เกี่ยวข้อง
3. ตำแหน่งและระยะที่สำรวจจริง โดยแยกจากพิกัด normalized ของภาพ
4. จำนวนกระชัง/เจ้าของ และข้อจำกัดการเข้าถึงที่ได้รับการยืนยัน
5. พฤติกรรมแรงดันตก/ไฟดับ โหลดจริง และชั่วโมงที่ต้องสำรอง พร้อมหลักฐานการวัด
6. ความเค็ม/การนำไฟฟ้า อุณหภูมิ และระดับน้ำหลายเวลา พร้อมการสอบเทียบและความลึกหัววัด
7. ผู้ดูแลและแผนบำรุงรักษาอุปกรณ์ การกัดกร่อน การรั่วซึม การติดตะไคร่ และขั้นตอนเมื่อค่าผิดปกติ

โมเดลนี้มีหน้าที่ช่วยคุยเรื่องสถานที่ ระบบไฟ และการทดลองให้เห็นภาพร่วมกัน การรับรองความตรงของพื้นที่และความพร้อมในการติดตั้งต้องอาศัยการสำรวจและทดลองจริงต่อไป
